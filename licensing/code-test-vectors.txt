# Pass-code test vectors. ONE source of truth for two implementations.
#
# PassCode.kt in the Android app reads codes; the licence Worker issues them. Two
# implementations of one checksum drift, and the failure is silent and awful: a code the
# buyer paid for that the app calls invalid, while they stand in front of a seller.
#
# Algorithm: Crockford Base32 alphabet, 7 payload characters plus 1 check character.
#   check = ALPHABET[ sum(value(c[i]) * (2i+1)) mod 32 ]
# The weights are ODD deliberately - see PassCode.checkCharacter for why, and for what it costs.
#
# Regenerate only when the algorithm changes deliberately. Never edit one line to make an
# implementation agree with itself.
#
# Format:  <input>  <TAB>  VALID|INVALID  <TAB>  <canonical body, or ->
